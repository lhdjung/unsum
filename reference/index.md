# Package index

## Main CLOSURE and SPRITE functions

- [`closure_generate()`](https://lhdjung.github.io/unsum/reference/closure_generate.md)
  : Generate CLOSURE samples
- [`sprite_generate()`](https://lhdjung.github.io/unsum/reference/sprite_generate.md)
  : Generate SPRITE samples

## Visualization

- [`closure_plot_bar()`](https://lhdjung.github.io/unsum/reference/closure_plot_bar.md)
  : Visualize CLOSURE data in a barplot
- [`closure_plot_ecdf()`](https://lhdjung.github.io/unsum/reference/closure_plot_ecdf.md)
  : Visualize CLOSURE data in an ECDF plot
- [`sprite_plot_bar()`](https://lhdjung.github.io/unsum/reference/sprite_plot_bar.md)
  : Visualize SPRITE data in a barplot
- [`closure_plot_horns_histogram()`](https://lhdjung.github.io/unsum/reference/horns-frequency.md)
  : Visualize horns index (\\h\\) frequencies
- [`demo_plot_bar()`](https://lhdjung.github.io/unsum/reference/demo-plot.md)
  : Visualize example distributions and their \\h\\ values

## Metrics

- [`closure_count_all()`](https://lhdjung.github.io/unsum/reference/closure_count_all.md)
  [`closure_count_initial()`](https://lhdjung.github.io/unsum/reference/closure_count_all.md)
  : Count CLOSURE samples in advance
- [`closure_gauge_complexity()`](https://lhdjung.github.io/unsum/reference/closure_gauge_complexity.md)
  : Heuristic to predict CLOSURE runtime
- [`horns()`](https://lhdjung.github.io/unsum/reference/horns.md)
  [`horns_uniform()`](https://lhdjung.github.io/unsum/reference/horns.md)
  [`horns_rescaled()`](https://lhdjung.github.io/unsum/reference/horns.md)
  : Horns index (\\h\\)

## Read and write

- [`closure_write()`](https://lhdjung.github.io/unsum/reference/closure_write.md)
  [`closure_read()`](https://lhdjung.github.io/unsum/reference/closure_write.md)
  : Write CLOSURE results to disk (and read them back in)
- [`sprite_write()`](https://lhdjung.github.io/unsum/reference/sprite_write.md)
  [`sprite_read()`](https://lhdjung.github.io/unsum/reference/sprite_write.md)
  : Write SPRITE results to disk (and read them back in)
